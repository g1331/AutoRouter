## 1. 公共视觉与页面结构

本清单按依赖顺序执行。页面编号对应 `specs/application-ui-experience/spec.md`。所有页面任务均包含中英文业务文案审查及 `design.md` 的视觉矩阵：桌面／移动、明暗／中英文常态检查，关联操作和错误状态按实际行为覆盖。测试数据仅限本地受控环境。

所有页面任务必须按 `design.md` 的 M01–M12 感知体验调查及页面映射，覆盖实际可达的控件、输入、浮层、切换、等待、数据更新、操作结果、排序、滚动和设备适配。每项实际触点记录“已优化／已验证保留”，不适用说明原因；新发现的同页体验断点继续处理，不能局限于用户示例。每页验收包含完整操作与动态过程，不能以静态截图通过、只有入场动画或通用清单打勾作为完成依据。

任务满足自身验收后立即勾选；每组结束执行阶段集成检查并提交，仅提交本变更相关文件，使用 Conventional Commit 并运行仓库提交钩子。阶段检查复用已通过结果，只在后续改动影响时重跑。阶段截图与命令结果附在对应任务下，供最终收口复核。
