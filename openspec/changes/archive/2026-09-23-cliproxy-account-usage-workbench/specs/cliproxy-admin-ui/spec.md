## ADDED Requirements

### Requirement: CLIProxyAPI 工作台信息层级

管理页面 SHALL 以实例选择和所选实例的账号用量为主工作区，关联上游与实例日志为可切换的次级视图。实例创建、启停、编辑、检测、删除、账号登录、同步、上传和账号行操作 MUST 保持可用。桌面和窄屏布局 MUST 使当前实例、当前视图和主要操作可辨认，关键账号信息无需横向裁切即可读取。单实例桌面工作区 MUST 使用侧栏之外的可用宽度，实例选中态 MUST 避免大面积着色。

#### Scenario: 桌面管理
- **WHEN** 管理员在桌面宽度选择一个实例
- **THEN** 页面清晰展示实例选择区、当前账号工作区和切换关联上游／日志的入口

#### Scenario: 窄屏管理
- **WHEN** 管理员在 320 至 390 像素宽度使用页面
- **THEN** 实例选择、账号状态、用量概况、主要操作和视图切换保持可见且可操作，页面不产生水平溢出

#### Scenario: 空白与失败状态
- **WHEN** 没有实例、没有账号，或任一独立视图加载失败
- **THEN** 该区域提供与状态对应的提示及现有的创建或重试入口，不遮蔽其他可用视图
